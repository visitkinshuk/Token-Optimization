## Project Overview

This academic project focuses on optimizing LLM prompts for sales analytics. It involved designing and refining three prompt versions to generate five management reports covering executive sales performance, regional performance, product performance, salesperson performance, and actionable business insights.

Through iterative prompt optimization, token consumption was reduced from **393 to 202 tokens (48.60%)** while retaining the required reporting specifications. The project demonstrates practical applications of prompt engineering, Generative AI, analytical reasoning, and evidence-based business insights.
